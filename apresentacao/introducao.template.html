O que vamos construir

Arquitetura do pipeline

O case é a GeloDados: uma rede fictícia de 5 lojas de sorvete e bebida gelada, espalhadas por 5 cidades brasileiras. O time comercial exporta as vendas diárias em CSV, mas ninguém sabe dizer se o clima influencia o resultado, porque essa informação não existe internamente: precisa vir de uma API pública. É a pergunta que vamos responder ao vivo, construindo o pipeline que junta os dois mundos.

Antes de começar

Passo a passo de instalação

# 1. clonar o repositório
git clone https://github.com/danietakeshi/workshop-pipeline-dados.git
cd workshop-pipeline-dados

# 2. ambiente Python
python -m venv .venv
source .venv/Scripts/activate   # PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. abrir o notebook da aula (Ctrl+C na janela pra encerrar e seguir)
pip install -r requirements-notebook.txt
jupyter lab notebooks/construindo_pipeline.ipynb

# 4. rodar o pipeline (CSV + API -> DuckDB)
python scripts/run_pipeline.py

# 5. subir o Metabase
docker compose up -d --build

Pré-requisitos: Python 3.11+, Git e Docker Desktop (aberto pelo menos uma vez antes de começar). Passo a passo completo e troubleshooting em SETUP.md e README.md no repositório.
